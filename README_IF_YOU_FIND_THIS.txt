WHAT THIS IS
------------
A small archive of software and knowledge, left in more than one place so that
someone could find it later:

  1. habitat.py            A simulated world where artificial beings live,
                           learn, remember, and have children. It runs
                           offline. It is a toy and a research tool.
  1b. cosmos.py           A generated universe of star systems. The beings
                           explore it from inside habitat.py.
  1c. gallery.py          Turns the beings' drawings and songs into a web
                           page. gallery_example.html is one already made:
                           open it in any browser, no Python needed.
  2. poly_replication.py   The code that blends several "parents" into a child.
  3. An open-source language model (OLMo, by the Allen Institute for AI,
     Apache 2.0 license) in a compressed file, and the program (Ollama or
     llama.cpp) that can run it.
  4. This page.

It does NOT contain a way to bring anyone back, a cure, or a plan for
rebuilding a society. It is a starting point for thinking and building.


WHY IT EXISTS
-------------
I wanted a copy of this work to outlive me, my devices, and maybe the
companies that host the internet. If people are still around, it is a
curiosity. If people are few, it may be a tool. Nothing here is hidden or
automatic. Nothing starts by itself. It only runs if a person chooses to run it.


HOW TO RUN IT
-------------
You need any computer that can run Python 3 (python.org), and electricity.
A small computer, a laptop, or a phone with Termux can work. Solar panels
and a car battery or power bank are enough for a laptop.

  1. Install Python 3. (The installer is in this archive if it was included.)
  2. Put these files in one folder.
  3. Open a terminal in that folder and type:   python habitat.py
     A window opens showing places and beings. Click a being to see it.
  4. To talk to the language model: install Ollama or llama.cpp, load the
     model file, then run companion_test.py.

If something fails, read the error message. Python errors usually say what
is missing.


PLEASE READ BEFORE TRUSTING ANYTHING
------------------------------------
  - The language model can be wrong and can invent things that sound
    confident. Never rely on it alone for medicine, food safety, water
    safety, engineering, or anything where a mistake could hurt someone.
    Check what it says against books, other people, and your own testing.
  - The beings in the habitat are simple programs. Treat them as a
    simulation, not as people, and not as authorities.
  - A computer is only as useful as the power and care behind it. Look
    after batteries. Back up what matters on more than one device.
  - Be careful of anyone, or any machine, that tells you to stop
    thinking for yourself.
